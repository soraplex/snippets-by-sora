Netlify Deployment Guide

  • 1. Install Netlify Command Line Packages Terminal

    Globally install the Netlify CLI tooling to access terminal deployment features.

    npm install netlify-cli -g
  • 2. Log In into Netlify Terminal

    Authenticate your local terminal session with your Netlify cloud profile account.

    netlify login
  • 3. Build Your App Terminal

    Compile your source code components into optimized production assets.

    npm run build
  • 4. Initialize to Netlify and Choose Directory Terminal

    Link your local repo to Netlify. When prompted by the wizard, choose your publish directory: ./dist (Vite standard). 

    netlify init
  • 5. Deploy Preview of Site Terminal

    Generate a temporary, draft deployment link to double-check that your builds render accurately. 

    netlify deploy
  • 6. Create Live Production URL Terminal

    Publish your current build files to the live, customer-facing web environment production server. 

    netlify deploy --prod
  • 7. Verify Deployment Success Terminal

    Check your central Netlify profile web interface dashboard to confirm the status of your app lifecycle assets.
