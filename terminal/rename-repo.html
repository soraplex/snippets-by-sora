• 1. Create the project directory Terminal

    Run the following command in your terminal to generate the folder structure:

    mkdir name_of_repo

ex: mkdir supermarket-data.js
  • 2. Move into the folder Terminal

    Change directories into your newly created project folder:

    cd <name_of_repo>
  • 3. Create files needed Terminal / GUI

    Can be done with the VS Code GUI if you prefer not to use the terminal.

    touch <name_of_file.extension>
// example: touch index.html
  • 4. Open in VS Code Terminal

    Launch the current directory workspace within your code editor:

    code .
  • 5. Initialize the repository Git

    Start tracking version history in this project folder:

    git init
  • 6. Push the repo to GitHub GitHub CLI

    Replace --public with --private if the repository is private. 

    gh repo create <name_of_repo> --public --source=.
  • 7. Check status Git

    Run this to ensure everything is initialized and working correctly:

    git status -v
