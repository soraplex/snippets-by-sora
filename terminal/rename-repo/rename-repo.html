Renaming a Repository

  • 1. Change the local folder name Terminal

    Step backward out of the project folder, rename it, and move back inside to prevent path lock errors: 

    cd ..
mv supermarket-data fresh-grocery-api
cd fresh-grocery-api
  • 2. Set the new remote origin URL Git

    Link your local workspace configuration to point to the newly updated remote URL destination on GitHub: 

    git remote set-url origin https://github.com/your_github_username/new_repo_name

ex: git remote set-url origin https://github.com/pretendAccount/fresh-grocery-api
  • 3. Verify remote connections Git

    Check the updated paths to confirm that both fetch and push locations are tracking correctly: 

    git remote -v

ex output:
origin https://github.com (fetch)
origin https://github.com (push)
