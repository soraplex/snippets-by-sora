Vite React Setup Guide

  • 1. Create React App Terminal

    Initialize your new application using Vite with the standard React template.

    npm create vite@latest <name_of_repo> -- --template react
  • 2. Move into the App Directory & Install Dependencies Terminal

    Navigate into your project folder and download the required node modules in one step. 

    cd <name_of_repo> && npm install
  • 3. Start Live Server Terminal

    Launch the local Vite development server to preview your application.

    npm run dev
