📁 1. Files & Folders (System)

  • Folders & Files: kebab-case

    Keeps names clean, consistent, and URL-friendly.

    user-profile/ profile-card.tsx

💻 2. Code Logic (JavaScript / TypeScript)

  • Variables & Functions: camelCase

    Starts lowercase, capitalizes subsequent words.

    const userProfile = {} function fetchInvoiceData()
  • Components, Classes & Types: PascalCase

    Capitalizes every word.

    const UserProfileCard = () => {} interface UserData {}
  • Global Constants / Env Variables: UPPER_SNAKE_CASE

    Fully capitalized with underscores.

    const API_KEY = '...'
  • Private / Internal Variables: _camelCase

    Prefixed with an underscore.

    let _secretToken = ''

🎨 3. Styling & Elements (HTML / CSS)

  • HTML Class Names: kebab-case

    Industry standard for CSS selectors; matches the file naming convention.

    <div class="profile-card-container">
  • HTML Element IDs: camelCase kebab-case

    Use descriptive names specifically reserved for unique JavaScript DOM hooks or layout anchoring.

    <form id="submit-billing-form">
