| Loop Type  | Simple Meaning                   | Best For                      |
| ---------- | -------------------------------- | ----------------------------- |
| `for`      | Count numbers                    | Repeat a set number of times  |
| `while`    | Keep going until something stops | Unknown number of repeats     |
| `do…while` | Do it once, then maybe again     | Must run at least once        |
| `for…of`   | Look at each item in a box       | Arrays / lists                |
| `forEach`  | Tell each item to do something   | Arrays / lists with functions |
