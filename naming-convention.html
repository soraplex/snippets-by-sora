📂 Repository Structure & Naming Conventions

🏗️ Directory Tree

src/
├── 📁 components/                  # Global, shared UI components
│   └── 📁 custom-button/
│       ├── 📄 custom-button.jsx     # The actual component file
│       ├── 📄 custom-button.test.js # Test file
│       └── 📄 custom-button.css     # Styling
├── 📁 features/                    # Domain-driven features (grouped by module)
│   └── 📁 user-profile/            # Feature Folder
│       ├── 📄 profile-card.jsx     # Sub-component
│       ├── 📄 use-profile.js       # Custom Hook
│       └── 📄 profile-api.js       # API helper
├── 📁 hooks/                       # Global custom hooks
│   └── 📄 use-local-storage.js
└── 📁 views/                       # Entire pages / routes
    └── 📄 user-dashboard.jsx

🔤 Code Casing Standards

  • Files & Folders: kebab-case (e.g., user-profile/, profile-card.tsx)
  • Variables & Functions: camelCase (e.g., userProfile, fetchData())
  • Components & Types: PascalCase (e.g., UserProfileCard)
  • Global Constants: UPPER_SNAKE (e.g., API_KEY)
